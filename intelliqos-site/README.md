# Intelliqos — рабочий сайт

Витрина продуктов (VMPOS, сайты под ключ, Telegram-боты, приложения,
ИИ-помощники) с приёмом заявок и заказов через собственный backend. Это уже
не макет: формы на сайте реально сохраняют заявки и заказы в базу данных,
модуль оплаты готов переключиться на настоящие Payme/Click, как только вы
получите мерчант-доступ, а на самом сайте работает живой чат-ассистент —
та же вещь, которую вы продаёте как пятый продукт.

## Что внутри

```
intelliqos-site/
├── public/              — сайт (index.html), админка (admin.html), логотип
└── server/              — backend на Node.js + Express + SQLite
    ├── src/server.js    — точка входа
    ├── src/routes/      — приём заявок, заказов и сообщений чата
    ├── src/lib/         — интеграция Payme, Click и ИИ-ассистент
    └── .env.example     — какие переменные окружения нужны
```

## Быстрый запуск локально

Нужен установленный Node.js версии 18 или новее.

```bash
cd server
npm install
cp .env.example .env      # заполните позже, для начала можно оставить пустым
npm start
```

Откройте `http://localhost:3000` — сайт заработает сразу: заявки и заказы
уже сохраняются в файл `server/data.db`, просто оплата на сайте пока не
переключена на реальные деньги (см. ниже).

Админка (список заявок и заказов): `http://localhost:3000/admin.html`.
Придумайте случайную строку и впишите её в `.env` как `ADMIN_TOKEN` — она
и будет паролем входа в админку.

## Что нужно сделать, чтобы сайт заработал «по-настоящему» в интернете

Ничего из этого нельзя оформить прямо из этой переписки — это реальные
юридические и организационные шаги, которые делает владелец бизнеса.
Дальше — по порядку.

### 1. Домен

Два разумных варианта:

- **`.uz`** — вызывает больше доверия у локальных клиентов. Регистрируется
  через одного из локальных регистраторов (например `webname.uz`, `ahost.uz`,
  `dc.uz`) — по их данным домен доступен физлицам, ИП и юрлицам, отдельного
  требования об обязательной регистрации компании в Узбекистане в открытых
  условиях не указано. Оплата — предоплатой на счёт регистратора.
- **`.com`** — быстрее и проще оформляется через международные сервисы
  (Namecheap, Cloudflare Registrar и т.п.), но чуть менее «узнаваем» для
  локального малого бизнеса.

### 2. Хостинг

Сайт лёгкий (Node.js + SQLite-файл), поэтому подойдёт почти любой VPS —
даже самый дешёвый (1 GB RAM хватает с запасом). Порядок действий на сервере:

1. Установить Node.js 18+.
2. Скопировать папку проекта на сервер (`git clone` или просто загрузить файлы).
3. `cd server && npm install --production`.
4. Заполнить `.env` (см. ниже).
5. Запустить через процесс-менеджер, чтобы сайт не падал при перезагрузке
   сервера, например [pm2](https://pm2.keymetrics.io/): `pm2 start src/server.js --name intelliqos`.
6. Настроить nginx как обратный прокси на порт из `.env` (`PORT`) и подключить
   бесплатный SSL-сертификат через Let's Encrypt (`certbot`). **SSL обязателен** —
   без него Payme и большинство платёжных систем работать не будут.

### 3. Payme Business

1. Подать заявку на подключение на `business.payme.uz` (для юрлица/ИП).
2. После одобрения вам выдадут **кассу** — merchant ID, а также логин и ключ
   для проверки запросов от Payme к вашему серверу.
3. Впишите их в `.env`:
   ```
   PAYME_MERCHANT_ID=...
   PAYME_MERCHANT_LOGIN=...
   PAYME_MERCHANT_KEY=...
   ```
4. Готово — как только эти переменные заполнены, кнопки оплаты Payme на сайте
   автоматически начинают вести на настоящую страницу оплаты `checkout.paycom.uz`,
   а сервер сам обрабатывает подтверждения от Payme (`/api/payments/payme`).
5. **Перед реальными деньгами обязательно протестируйте** в тестовой кассе
   Payme (её тоже выдают при подключении) и сверьтесь с официальной
   документацией: developer.help.paycom.uz — протокол Merchant API может
   уточняться, а наш код реализует его по состоянию на момент разработки.

### 4. Click

1. Подать заявку на подключение бизнеса в Click (личный кабинет для бизнеса
   на `my.click.uz`).
2. После одобрения получите `merchant_id`, `service_id` и `secret_key`.
3. Впишите их в `.env`:
   ```
   CLICK_MERCHANT_ID=...
   CLICK_SERVICE_ID=...
   CLICK_SECRET_KEY=...
   ```
4. Так же, как с Payme — заполненные переменные сразу включают реальную
   оплату через Click.
5. Тоже обязательно протестируйте в тестовом режиме перед боевыми платежами
   и сверьтесь с docs.click.uz — там могут быть нюансы в порядке полей подписи.

### 5. Uzcard / Humo и карты Visa/Mastercard

У Payme и Click уже есть приём карт Uzcard/Humo в рамках их обычного
подключения — отдельная интеграция для них, как правило, не нужна. Уточните
у менеджера при подключении Payme/Click, какие именно карты поддерживает
ваш конкретный договор (иногда Visa/Mastercard требует отдельного пункта
в договоре или отдельного тарифа). Сайт уже устроен так, что способы оплаты
«Uzcard/Humo» и «карта» автоматически используют тот шлюз, который у вас
настроен (по умолчанию — Payme, если настроены оба).

### 6. Юридическое оформление

Почти всегда для подключения Payme/Click нужен статус ИП или ООО в
Узбекистане и расчётный счёт в банке. Если этого ещё нет — это стоит
оформить в первую очередь, до подачи заявок в платёжные системы: без него
заявку на подключение, скорее всего, не примут. Это не техническая, а
организационная задача — обычно её берёт на себя бухгалтер или юрист.

### 7. ИИ-ассистент на сайте (пятый продукт и его же живая витрина)

На сайте есть чат-виджет (кнопка в правом нижнем углу) — это одновременно
демонстрация продукта «ИИ-помощники» и реально работающий помощник для
ваших посетителей.

**Работает уже сейчас без единой настройки.** Без ключа ассистент отвечает
по ключевым словам на основе каталога продуктов и цен (`server/src/lib/assistant.js`,
переменная `CATALOG_TEXT`) — это не заглушка для вида, а рабочий, просто менее
гибкий к формулировкам режим.

**Чтобы включить полноценный ИИ-режим** (ассистент понимает вопрос своими
словами, а не только по ключевым словам):
1. Зарегистрируйтесь на `platform.claude.com`, привяжите способ оплаты и
   создайте API-ключ.
2. Впишите его в `.env`:
   ```
   ANTHROPIC_API_KEY=...
   ```
3. Готово — сайт сам переключится на живой ИИ, менять код не нужно.

**Про стоимость.** Это отдельная платная услуга от Anthropic, не входящая в
разработку сайта — оплата идёт по количеству использованных токенов (по
факту обращений посетителей к ассистенту). Мы используем самую дешёвую и
быструю модель (Haiku), запрос обычно стоит доли цента. Актуальные цены —
`platform.claude.com/docs/en/about-claude/models`. Если сайт станет
популярным, стоит время от времени проверять расход в личном кабинете.

**Защита от накрутки счёта:** на эндпоинт `/api/assistant` уже встроен
лимит — не больше 20 сообщений в минуту с одного IP-адреса.

**Что видно в админке:** вкладка «Диалоги с ассистентом» на `/admin.html`
показывает все вопросы и ответы — удобно, чтобы понять, что реально
спрашивают клиенты, и доработать каталог или сам сайт под это.

## Что уже работает без ожидания реальных платежей

- Форма «Быстрая заявка», кнопки «Обсудить проект/задачу/ТЗ», «Запросить
  демо-версию», «Заказать выезд» — сохраняют заявку в базу и показывают
  клиенту честное сообщение, что с ним свяжутся. Ничего не имитируется.
- Кнопки покупки создают заказ в базе. Если оплата ещё не подключена —
  сайт честно говорит об этом и обещает связаться, а не притворяется,
  что деньги списаны.
- Всё видно в админке (`/admin.html`) сразу, без ожидания интеграций.
- Чат-ассистент отвечает посетителям сразу, даже без ключа Anthropic —
  просто в более простом, но всё равно полезном режиме.

## Дальнейшие возможные улучшения (не обязательно прямо сейчас)

- Уведомления в Telegram-бот или на почту о новой заявке/заказе — сейчас
  заявки просто копятся в базе, их видно в админке при заходе.
- Более точная сверка протоколов Payme/Click с реальными тестовыми кассами.
- Перенос базы с SQLite на PostgreSQL, если заказов станет действительно
  много (для старта SQLite более чем достаточно).
